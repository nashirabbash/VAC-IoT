2. Struktur Payload JSON (Outbound / Inbound)

Outbound (App ➔ Hardware via RX)

// 1. Authenticate Handshake
{"type": "auth", "pin": "123456"}

// 2. Time Synchronization
{"type": "time_sync", "timestamp": 1785235200}

// 3. Konfigurasi WiFi
{"type": "wifi_config", "ssid": "MyClinicWiFi", "password": "SecretPassword"}

Inbound (Hardware ➔ App via TX)

// 1. WiFi Status Broadcast
{"type": "wifi_status", "status": "CONNECTED", "ssid": "MyClinicWiFi"}

// 2. Therapy Event Data (Otomatis Disimpan ke SQLite via TherapyReceiver)
{
  "type": "therapy_event",
  "start": 1785230000,
  "title": "Sesi Terapi Luka",
  "date": "2026-07-29 10:00",
  "mode": "Kontinyu",
  "duration": "30 Menit"
}

3. Algoritma RSSI Proximity Guard

  • Interval Polling: Tiap 4 detik via device.readRssi()
  • Batas Ambang Jarak (Threshold): -85 dBm (~8-10 meter)
  • Aturan Disconnect: Jika RSSI < -85 dBm sebanyak 3 kali berturut-turut (_lowRssiCount >= 3), app memutus koneksi (disconnect()) untuk hemat daya dan menjaga keamanan.

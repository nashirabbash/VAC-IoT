Pelajaran 0001 — BLE Fundamentals

Konsep Komunikasi Bluetooth Low Energy (BLE)

Memahami arsitektur, alur data, dan protokol komunikasi antara Aplikasi Flutter dan Perangkat Medis VAC STECHOQ.

🎯 Ringkasan Utama

Aplikasi ini menggunakan package flutter_blue_plus di file lib/services/ble_service.dart untuk mengelola koneksi nirkabel ke hardware ESP32 VAC. Komunikasi menggunakan model GATT (Generic Attribute Profile) dengan payload JSON melalui stream dua arah (RX/TX).

1. Arsitektur Komunikasi BLE (GATT)

Dalam ekosistem BLE, terdapat dua peran utama:

  • GATT Client (Smartphone / Flutter App): Menginisiasi pemindaian (scan), melakukan koneksi, serta menulis dan menerima pesan.
  • GATT Server / Peripheral (VAC STECHOQ / ESP32): Memancarkan sinyal Bluetooth (Advertising) dan menyediakan Service & Characteristics.

2. Komponen Utama GATT UUID

Setiap layanan dan saluran data pada perangkat VAC STECHOQ diidentifikasi oleh UUID 128-bit khusus:

1. Service UUID (4fafc201-1fb5-459e-8fcc-c5c9c331914b)

Layanan utama tempat seluruh fitur VAC STECHOQ dikelompokkan.

2. RX Characteristic — Write Channel (c083b0f6-bb21-4f15-8120-d4f13b28b7e2)

Saluran tempat smartphone mengirimkan perintah ke hardware (App ➔ ESP32). Metode tulisan menggunakan UTF-8 JSON.

3. TX Characteristic — Notify Channel (6e400003-b5a3-f393-e0a9-e50e24dcca9e)

Saluran tempat hardware mengirimkan data/status secara real-time ke smartphone (ESP32 ➔ App) melalui notifikasi Push.

3. Alur Handshake & Sinkronisasi Waktu

Setiap kali koneksi BLE terhubung (_connect), aplikasi melakukan urutan alur berikut secara otomatis:

  1. Subscribe Notifikasi TX: _txChar.setNotifyValue(true) dipanggil agar aplikasi siap mendengarkan byte masuk dari hardware.
  2. Autentikasi Otomatis: Mengirimkan paket {"type": "auth", "pin": authPin} ke kanal RX.
  3. Sinkronisasi Jam (Time Sync): Mengirimkan Unix Timestamp terkini {"type": "time_sync", "timestamp": epoch_seconds} agar waktu pada hardware presisi dengan jam smartphone.
  4. Stream Event Terapi: Hardware mengirim data sesi terapi via TX. Aplikasi memvalidasi payload dan langsung menyimpannya ke database SQLite lokal via TherapyReceiver.save(data).
// Contoh Potongan Kode Handshake pada BleService (lib/services/ble_service.dart)
if (authPin != null && authPin.isNotEmpty) {
  await send('auth', {'pin': authPin});
}

final ts = DateTime.now().millisecondsSinceEpoch ~/ 1000;
await send('time_sync', {'timestamp': ts});

4. Pemantauan Jarak (RSSI) & Auto-Reconnect

Aplikasi dilengkapi dengan mekanisme perlindungan koneksi cerdas:

  • Monitoring RSSI: Setiap 4 detik (_startRssiMonitoring), aplikasi mengecek kekuatan sinyal nirkabel (dBm).
  • Proximity Threshold: Sinyal di bawah -85 dBm dianggap jarak terlalu jauh (> 8-10 meter).
  • Proteksi Pemutusan: Jika terdeteksi 3 kali berturut-turut sinyal lemah, koneksi BLE sengaja diputus (disconnect()) untuk menghemat daya baterai.
  • Silent Auto-Reconnect: Jika koneksi terputus secara tidak disengaja (misal pengguna keluar ruangan), background scanner akan otomatis mencoba reconnect saat pengguna mendekat kembali.

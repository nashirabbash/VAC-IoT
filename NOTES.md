# Notes: User Preferences & Learning Scratchpad

## Prefensi Pembelajaran User
- Bahasa pengantar: Bahasa Indonesia yang jelas, komunikatif, dan terstruktur.
- Gaya pembelajaran: Konseptual dengan mengaitkan langsung ke kode asli yang ada pada aplikasi (`lib/services/ble_service.dart`).
- Menggunakan visualisasi HTML interaktif + Kuis singkat untuk memperkuat retensi memori (Storage Strength).
